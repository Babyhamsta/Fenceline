# Design docs

Design specs and implementation plans for major Fenceline features. Specs
capture the intended behaviour and trade-offs; plans are the step-by-step build
breakdowns they were implemented from. Kept for context on *why* things are the
way they are — they are historical records, not living documentation (the README
and code comments are authoritative for current behaviour).
