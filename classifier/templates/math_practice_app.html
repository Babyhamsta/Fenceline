Fraction Practice

Solve each problem and type your answer in lowest terms. The app checks your work instantly and keeps a running score so you can track which skills need more practice.

Question 2: What is 2/3 - 1/6 ?

Adding fractions requires a common denominator. Once the denominators match you add only the numerators and keep the denominator the same, then simplify the result if possible.

Teachers can assign these drills for homework or warm-ups. Each session generates a fresh set of randomized problems so students get unlimited practice without repeating the same answers.
