# Block-the-page-never-pin-the-origin hosts.
#
# These render MANY independent sites' content under one origin
# (path-multitenant). Fenceline still blocks the specific harmful page (the
# content scan re-runs every visit), but never PINS the bare host — pinning
# would over-block the whole service (pinning sites.google.com kills all Google
# Sites; pinning web.archive.org kills the Wayback Machine for legit research).
#
# Suffix-matched, so subdomains are covered. Shipped in meta.json and synced to
# the fleet, so additions land in days instead of an extension-release cycle.
# The extension ships this same set bundled as a pre-first-sync fallback
# (extension/lib/pins.js). Districts extend it via the extraNoPinHosts policy
# key without forking. One host per line; # starts a comment.
